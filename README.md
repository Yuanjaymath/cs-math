# 整數突擊 / CS Math v0.16.0

東興 鍾元杰 製作

瀏覽器中的國中數學第一人稱練習遊戲。HTML5、CSS、JavaScript 與原生 WebGL，無需安裝套件。

## 遊玩
開啟 GitHub Pages 網站即可遊玩，學生不需要 GitHub 帳號。電腦使用 WASD 移動、滑鼠瞄準、左鍵射擊、右鍵武器特殊功能；平板使用左右搖桿與射擊鍵。T 顯示戰鬥提示，M 切換音樂，Esc 暫停。

選擇整數四則（含絕對值）或科學記號題庫。四名機器人各有一個選項，只射擊正確答案。錯答扣血；敵人子彈可閃躲，掩體可擋彈。答對後双方停火，直到新題出現。進度與音樂設定保存在使用者自己的瀏覽器，沒有上傳學生紀錄。

## v0.16.0
- 出場間距加大、前四秒分散巡邏；後續採分散包圍，避免集中追同一點。
- 移動保持敵人間距；答案牌自動避讓並以連線指向所屬機器人。
- 右上角固定顯示製作者與版本。
- 兩大題庫、十五類科學記號、音樂、逐發槍聲與觸控操作。

網站入口 index.html；index.htm 為相同內容。必要檔案在 cjs，聲音在 cjs/sound。素材由製作者提供。
